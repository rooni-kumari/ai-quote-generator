# AI Quote Generator

The AI Quote Generator is a beginner-friendly Python project developed using Google Colab. This project uses a Generative AI API to generate creative and motivational quotes automatically.

## Features
- Generates AI-based quotes instantly  
- Beginner-friendly Python code  
- Uses secure API key method  
- Works in Google Colab  
- Useful for learning and inspiration  

## Technologies Used
- Python  
- Google Colab  
- Generative AI API  

## How to Run
1. Open the notebook in Google Colab  
2. Enter your API key  
3. Run all cells  
4. Get AI-generated quotes
